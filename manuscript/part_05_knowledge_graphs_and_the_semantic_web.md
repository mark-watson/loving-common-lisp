-# Part 5: Knowledge Graphs and the Semantic Web

Knowledge graphs are how we give programs a memory of facts and relationships. In this part we work with RDF and SPARQL, including a small datastore and partial SPARQL engine that we write ourselves; generate and sample graph data; build the Knowledge Graph Navigator library and its text-based and LispWorks CAPI user interfaces; and finish with a neural-symbolic engine that combines graph traversal with language models.
