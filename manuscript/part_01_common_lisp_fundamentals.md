# Part 1: Common Lisp Fundamentals

Before we build anything interesting we need to be comfortable with the language itself. This part covers the syntax you type at the REPL, how to organize code into files and systems with Quicklisp, how to define functions and macros, how to write loops that do not make your eyes bleed, how packages keep names from stepping on each other, and how to read and write data. Everything later in the book assumes you can find your way around this material.
