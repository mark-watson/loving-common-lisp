# Part 8: macOS Specific Code Experiments

Not everything I write is portable, and this part is where the macOS-only code lives. The first chapter builds native desktop applications with Common Lisp, CFFI, Cocoa, and WebKit: real windows, HTML and CSS user interfaces, and a two-way bridge between Lisp and JavaScript. More experiments that lean on Apple's frameworks and Apple Silicon will be added here as I write them up.
