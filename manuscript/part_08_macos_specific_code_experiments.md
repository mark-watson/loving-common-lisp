# Part 8: macOS Specific Code Experiments

Not everything I write is portable, and this part is where the macOS-only code lives. The first chapter builds native desktop applications with Common Lisp, CFFI, Cocoa, and WebKit: real windows, HTML and CSS user interfaces, and a two-way bridge between Lisp and JavaScript. The next chapter automates Mail, Calendar, Messages, Reminders, and Safari through AppleScript, and the last chapter wraps that code in a Model Context Protocol (MCP) server so LLM clients such as Claude Code can call it as tools. More experiments that lean on Apple's frameworks and Apple Silicon will be added here as I write them up.
